# Study 1: literature review

**Question.** How have thermal performance curves been used to predict temporal community stability?

**Input.** `data/literature_file.xls`, the screening and extraction table.

**Run.** From the repository root, use `source("reproduce.R")`, or render only this report with `quarto render studies/01_literature/report.qmd`.

**Output.** Supplementary Information 1 in `outputs/reports/` and `outputs/submission/` when run through the root workflow.

**Runtime.** Typically under one minute. Screening decisions and exclusions are recorded in the input workbook and explained in the report.
